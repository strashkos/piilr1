# Лабораторна робота №1 — Реєстрація доменного імені

Дисципліна «Програмування в Інтернет». PHP-застосунок без фреймворку: форма, серверна валідація, ООП, Composer PSR-4.

## Індивідуальні параметри

| Параметр | Значення |
|---|---|
| Номер у журналі N | 19 |
| Варіант | 61 — Реєстрація доменного імені |
| K = 100 + 5 × (N mod 5) | 120 % |
| L = 3 + (N mod 4) | 6 записів історії |
| Заголовок відповіді | `X-Student-Variant: 19-61` |

## Варіант 61

- Поля: домен; строк у роках (1–10); доменна зона; дата початку; коментар (необов’язковий).
- Зони: `ua` — 650 грн/рік, `com` — 520, `org` — 480.
- Вартість = роки × ставка; від 5 років знижка 8 %; зона `ua` додає перевірку даних 200 грн; потім × K / 100 з округленням до цілого.
- Домен: 3–100 символів, містить крапку, без пробілів.
- Історія: останні L = 6 заявок у session, GET-фільтр `/?zone=ua|com|org`.
- Після успішного POST — redirect 303 на `/?created=1` (Post/Redirect/Get).

### Граничний тест варіанта

| Вхід | Очікування |
|---|---|
| `example` (без крапки) | помилка «Домен повинен містити крапку» |
| `my site.com` (з пробілом) | помилка «Домен не повинен містити пробілів» |
| `example.com` | приймається |
| `com`, 4 роки | 4 × 520 = 2080 × 1,2 = **2496 грн** (без знижки) |
| `com`, 5 років | 5 × 520 × 0,92 = 2392 × 1,2 = **2870 грн** (знижка 8 %) |
| `ua`, 4 роки | (4 × 650 + 200) × 1,2 = **3360 грн** |
| `ua`, 5 років | (5 × 650 × 0,92 + 200) × 1,2 = **3828 грн** |

## Запуск

```bash
composer install
composer validate --strict
composer serve
```

Відкрити http://127.0.0.1:8000, зупинити сервер — Ctrl+C.

```
composer.json

public/style.css

views/form.php                HTML-форма
views/history.php             історія заявок і фільтр
```
