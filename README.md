# Лабораторна робота №1 — Реєстрація доменного імені

Дисципліна «Програмування в Інтернет». PHP-застосунок без фреймворку: форма, серверна валідація, ООП, Composer PSR-4.

## Індивідуальні параметри

| Параметр | Значення |
|---|---|
| Номер у журналі N | 19 |
| Варіант | 61 — Реєстрація доменного імені |
| K = 100 + 5 × (N mod 5) | 120 % |

## Варіант 61

- Поля: домен; строк у роках (1–10); доменна зона; дата початку; коментар (необов’язковий).
- Зони: `ua` — 650 грн/рік, `com` — 520, `org` — 480.
- Вартість = роки × ставка; від 5 років знижка 8 %; зона `ua` додає перевірку даних 200 грн; потім × K / 100 з округленням до цілого.
- Домен: 3–100 символів, містить крапку, без пробілів.

## Запуск

```bash
composer install
composer validate --strict
composer serve
```

Відкрити http://127.0.0.1:8000, зупинити сервер — Ctrl+C.
